ASUS ROG STRIX X570-F Gaming · Ryzen 5 5600X

Switch to UEFI, then install Windows 11

Your PC meets every Windows 11 requirement. It's starting up in the old Legacy mode, which hides Secure Boot and the security chip (TPM) from Windows. These steps switch it to UEFI mode. Your files and apps stay where they are.

What System Information (msinfo32) shows now, and after these steps

BIOS ModeLegacy→UEFI
Secure Boot StateUnsupported→On

Takes about 30–45 minutes, plus the Windows 11 install at the end.

Before you start

  • Open this page on your phone. Your PC will be in the BIOS for part of this, so you won't be able to read it there.
  • A USB stick formatted as FAT32. To check, right-click the stick in File Explorer and choose Properties. If File system doesn't say FAT32, right-click the stick, choose Format, pick FAT32 and click Start. This erases everything on the stick. Sticks bigger than 32 GB often don't offer FAT32, so a smaller stick is easiest.
  • Back up anything you can't lose. Nothing should get deleted, but you're changing how the drive is set up.
Do the steps in order. Convert the drive (step 2) before you turn off CSM (step 3). If you do step 3 first, Windows won't start. You can still fix that easily: see "If something goes wrong" at the bottom.

0 of 5 steps done

  1. 1
    In Windows, then the BIOS

    Update the BIOS

    Do this first. The update resets every BIOS setting, so anything you change before it would be lost.

    1. Go to asus.com/support and search for ROG STRIX X570-F GAMING. Open its BIOS & Firmware downloads and download the newest BIOS at the top of the list.
    2. Unzip the download and copy the .CAP file onto the USB stick. The download also includes BIOSRenamer. You don't need it for this method: it's only for the BIOS FlashBack button on the back of the PC. Running it anyway does no harm.
    3. Plug the stick into a USB port on the back of the PC. Restart, and keep tapping Del while it starts up to open the BIOS.
    4. Press F7 for Advanced Mode, then go to Tool›ASUS EZ Flash 3 Utility.
    5. Choose via Storage Device(s), pick the USB stick, select the .CAP file and confirm.
    6. Wait for it to finish. It restarts by itself, sometimes more than once. Don't turn the PC off during the update.

    RAM speed. The update turns off the memory speed profile. If your RAM was running at its rated speed before, turn it back on in Ai Tweaker›Ai Overclock Tuner → D.O.C.P. You can do this during step 3.

    Your USB problem. Newer BIOS versions include AMD's fix for USB devices randomly disconnecting on X570 boards, so this might help your headset too.

  2. 2
    In Windows

    Convert the drive to GPT

    UEFI mode needs the Windows drive set up the newer way (GPT instead of MBR). Windows has a built-in tool for this that doesn't delete anything.

    1. Click Start and type cmd. Right-click Command Prompt, choose Run as administrator, then click Yes.

    2. Check that the drive can be converted:

      >mbr2gpt /validate /allowFullOS

      You should see: Validation completed successfully

    3. Convert it:

      >mbr2gpt /convert /allowFullOS

      You should see: Conversion completed successfully. A warning about switching the firmware to UEFI mode is normal. That's step 3.

    4. Restart and keep tapping Del to go straight into the BIOS.

    If either command shows an error, stop here. Take a screenshot of the error and send it. Don't go on to step 3.

  3. 3
    In the BIOS

    Change three BIOS settings

    If the BIOS opens in the simple EZ Mode, press F7 for Advanced Mode. You can use the mouse or the arrow keys.

    1. Turn on UEFI mode Boot›CSM (Compatibility Support Module)›Launch CSM → Disabled
    2. Turn on the TPM Advanced›AMD fTPM configuration›TPM Device Selection → Firmware TPM If it asks you to confirm, choose OK.
    3. Turn on Secure Boot Boot›Secure Boot›OS Type → Windows UEFI mode
    4. Press F10, then OK to save and exit. The PC restarts into Windows.
  4. 4
    In Windows

    Check that it worked

    1. Press Win + R, type msinfo32 and press Enter. Look for:

      BIOS ModeUEFI
      Secure Boot StateOn

    2. Press Win + R, type tpm.msc and press Enter. Look for:

      StatusThe TPM is ready for use
      Specification Version2.0

    If both match, your PC is ready for Windows 11.

  5. 5
    In Windows

    Install Windows 11

    1. Open Settings → Windows Update → Check for updates. If Upgrade to Windows 11 shows up, click Download and install.
    2. If it doesn't show up yet, download the Windows 11 Installation Assistant from microsoft.com/software-download/windows11 and run it.

    The upgrade keeps your files and apps. It takes about an hour and restarts a few times.

If something goes wrong

Windows won't start after step 3

You might see "Reboot and select proper boot device", or the PC goes straight back into the BIOS. This usually means the drive wasn't converted.

In the BIOS, set Boot›CSM›Launch CSM → Enabled and press F10. Windows starts normally again. Then do step 2 and try step 3 again.

Also check that Boot›Boot Option #1 is set to Windows Boot Manager.

Windows won't start right after the BIOS update

The update reset CSM. Use the same fix: set Boot›CSM›Launch CSM → Enabled, press F10, then carry on with step 2.

Secure Boot State still says Off

In the BIOS, go to Boot›Secure Boot›Key Management and choose Install Default Secure Boot keys. Press F10 to save.

mbr2gpt shows an error

Don't carry on with step 3. Take a screenshot of the message and send it, so someone can tell you what's blocking it. Your PC keeps working normally in the meantime.

I can't find a setting in the BIOS

Menu names can differ slightly between BIOS versions. Newer versions have a Search button along the top of the screen. Type the setting's name, like "CSM" or "fTPM".
